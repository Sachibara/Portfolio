# OpsFusion — maintained application

The active OpsFusion IT Workspace and Employee Support Portal are maintained in [Sachibara/HelpDesk-Pro](https://github.com/Sachibara/HelpDesk-Pro).

- [IT Workspace](https://opsfusion-it.vercel.app/)
- [Employee Support Portal](https://opsfusion-it.vercel.app/employee)
- [Current capabilities, access model and verification limits](https://github.com/Sachibara/HelpDesk-Pro#readme)

OpsFusion connects a shared IT operations workspace with an employee support portal. Workspace owners manage individual staff accounts; authorized members handle tickets, inventory, Knowledge Base articles, AI-assisted work notes and scheduled alerts. Employees submit and track their own requests through a separate portal.

This portfolio directory is a legacy source snapshot. Its historical diagnostic, remote-support and local-demo code does not describe the deployed product. Its entry page now links to the maintained system; no legacy application scripts are loaded. Real endpoint control and telemetry still require agent integrations.

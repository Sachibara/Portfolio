SECURITY & RESILIENCE

Policy boundaries with failure tolerance.

The project intentionally combines availability and security because enterprise networks must preserve service while restricting unnecessary access.

GUEST POLICY

Internet only

HQ and branch guest networks are denied access to RFC1918 enterprise networks and permitted outbound Internet traffic.

DMZ POLICY

Public web, isolated inside

The DMZ web server is statically published while an inbound SVI ACL prevents it from initiating sessions toward protected internal VLANs.

MANAGEMENT

SSH only

Routers and switches use local authentication, SSH v2, and VTY access restrictions to the IT administration subnet.

ACCESS LAYER

Sticky port security

User-facing access ports use sticky MAC learning, limited MAC counts, and PortFast.

GATEWAY HA

HSRP load sharing

DIST1 and DIST2 split active HSRP roles by VLAN and preempt after recovery.

L2 RESILIENCE

STP + LACP

Rapid-PVST root placement aligns with HSRP while the distribution interconnect uses LACP EtherChannel.

FAILURE TESTS

What must be proven in Packet Tracer.

F01Power off DIST1 while continuously pinging the Internet from VLAN 10.HSRP/STP reconverges through DIST2.
F02Shut one LACP member between distribution switches.Port-channel remains operational.
F03Shut EDGE1 ↔ DIST1 routed link.OSPF keeps HQ routes available through DIST2.
F04Test HQ Guest → Server VLAN.Denied by guest ACL.
F05Test Internet client → 203.0.113.3 TCP/80.Static NAT reaches DMZ web server.
F06Attempt Telnet to network devices.Rejected; SSH remains available from IT admin VLAN.

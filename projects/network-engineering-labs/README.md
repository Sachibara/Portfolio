# Enterprise Network Engineering Lab Suite

A consolidated set of **Cisco Packet Tracer–ready enterprise networking projects** for the Jim Rodmark Camus portfolio.

> These files provide the engineering design, addressing, IOS configuration templates, validation plan, and troubleshooting evidence requirements. The proprietary Cisco Packet Tracer `.pkt` binary must be saved from Cisco Packet Tracer after building and validating each topology.

## Portfolio Evidence Standard

For every completed Packet Tracer file, add:

- final topology screenshot
- `.pkt` file
- device configuration exports
- `show ip route`
- `show ip ospf neighbor` where applicable
- redundancy/failover proof
- ACL/NAT verification where applicable
- end-to-end ping/application tests
- a short problem/design/validation write-up

The goal is to demonstrate **network engineering judgment, validation discipline, and troubleshooting**, not merely that IOS commands were entered.
